# NAI Studio

NovelAI 이미지 생성 API를 쓰는 Windows 앱 NAI Studio의 설치 파일을 올리는 곳입니다. 소스 코드는 비공개 레포에 있습니다.

## 설치

[최신 버전](https://github.com/cafephilia/nai-studio-releases/releases/latest)에서 `NAI-Studio-Setup-<버전>.exe`를 받아 실행하세요.

- 코드 서명이 없어서 Windows SmartScreen이 경고하면 "추가 정보 → 실행"을 누르세요.
- NovelAI 계정과 API 토큰이 필요합니다. 그림을 만들 때 그 계정의 Anlas를 씁니다.
- 설치한 앱은 새 버전이 나오면 받아 두었다가 다시 시작해 설치할지 묻습니다.
- 설정과 갤러리는 `%APPDATA%\NAI Studio`에 저장되고, 앱을 지워도 남습니다.
